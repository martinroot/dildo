Why it works

LoRA, not full retraining

Instead of rewriting 0.8 B parameters, we train a ~30 MB low-rank residual on top of Qwen3.5. Measured on a $0.17/h RTX 3090: a smoke run (12 steps) finishes end-to-end in ~10 min for ~$0.03; a standard run (160 steps) in ~30 min for $0.08–0.12.

Zero idle billing

The control plane rents a GPU only for the run: uploads data and trainer over SSH, streams live progress back, collects artifacts and releases the instance. You never pay for a parked machine.

Nothing ships unverified

Every adapter is evaluated on held-out examples against the base model. If accuracy, JSON validity or regression gates fail, activation is blocked — you see exactly which check failed.
